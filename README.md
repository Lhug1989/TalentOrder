# TalentOrder

An addon for **WoW Forever** (Interface 16001). It spends your talent points in the order you planned, for any class.

**Download:** [TalentOrder.zip](https://github.com/Lhug1989/TalentOrder/releases/latest/download/TalentOrder.zip) (one click, always the newest version)

## What it does

- **Planner** (`/to plan`): your three talent trees side by side. Left click plans a point, right click takes the last point of that talent back. Undo last and Clear plan are there too.
- **Auto-spend** (`/to on`): each time you gain a talent point, it is spent on the next step of your plan.
- **Status** (`/to`): shows whether it is on and which order it follows.
- A built-in order for rogues, used until you make your own plan.

Plans are saved per character.

## Install

1. Download the zip with the link above.
2. Unzip it into `World of Warcraft/_forever_/Interface/AddOns/` (you should end up with a folder `AddOns/TalentOrder`).
3. Start the game and type `/to plan`.
